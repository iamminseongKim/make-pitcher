# ACE PROJECT

모바일 브라우저에서 플레이하는 투수 육성 아케이드 게임입니다. 원안은 [prd.md](./prd.md), 구현 범위와 조정한 규칙은 [GAME_PLAN.md](./GAME_PLAN.md)에 정리했습니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
pnpm install
pnpm dev
```

`http://localhost:5173`에서 열 수 있습니다. 배포 빌드는 `pnpm build`입니다.

## 플레이

1. 이름, 키, 투구 손, 팔각도, 타격 난이도를 정하고 시작 구종을 1~3개 고릅니다. 구종을 적게 고를수록 시작 스탯이 높습니다.
2. 경기장 안 투수 손 방향의 작은 구종 버튼으로 공을 고릅니다. 예상 궤적과 제구 범위가 표시됩니다.
3. 스트라이크 존을 터치해 도착 지점을 고릅니다. **미터 시작**을 누른 뒤 밝은 파워 구간에서 **파워 결정**을 눌러 투구합니다.
4. 실제 투구 궤적은 다음 투구가 시작될 때까지 화면에 남습니다. 삼진·아웃·이닝 종료로 TP를 모아 우측 상단 훈련실에서 스탯을 올리거나 구종을 해금합니다.

타격 난이도는 선수 프로필에서 바꿀 수 있습니다. 루키/프로/레전드는 타자 접촉 확률과 TP 배율(×1.0/×1.5/×2.2)에 영향을 줍니다.

진행 상황은 브라우저의 `localStorage`에 자동 저장됩니다. 브라우저가 진동을 지원하면 퍼펙트 투구와 강속구에 햅틱이 작동합니다. 소리는 우측 상단에서 끌 수 있습니다.
