# ACE PROJECT

모바일 브라우저 투수 육성 게임. 원안은 [prd.md](./prd.md), 규칙은 [GAME_PLAN.md](./GAME_PLAN.md).

## 실행

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm build
pnpm test         # 회귀 테스트 (물리·미터·타자 AI·스태미너·시즌 기록·세이브 마이그레이션·하이라이트/일일 미션/이름 중복)
pnpm sim          # 투구 전략 × 리그별 K% / BB% / 피안타율 밸런스 시뮬레이션
pnpm sim:platoon  # 구종 × 같은 손/반대 손 헛스윙률 점검
```

## 플레이

1. 이름·키·투구 손·팔 각도·주무기(1~3개)를 정하고 **Amateur**에서 데뷔합니다. 키와 팔 각도가 익스텐션·릴리스 높이·IVB·VAA를 결정하며, 생성 화면에서 바로 확인할 수 있습니다.
2. 상대 9명 타선이 순서대로 들어옵니다. 타자마다 우타/좌타/스위치, 핫존, 약점 구종, 기세가 다릅니다.
3. 구종 칩 → 존 터치 → **투구 → 릴리스!** 두 번 탭 (데스크톱은 스페이스바).
4. 3아웃이면 우리 타선 공격이 자동 진행되고, 9회가 끝나면 승패가 결정됩니다.
5. 체력이 떨어지면 감독이 올라옵니다. 공을 넘기면 불펜이 경기를 마무리합니다.
6. TP로 훈련실에서 구속·제구·무브먼트를 올리고 새 구종을 해금합니다.

## 리그 = 난이도 (Difficulty System)

별도의 루키/프로/레전드 선택은 없앴습니다. 현재 리그가 곧 난이도이며, 헤더 아래 리그 배너와 데스크톱 좌측 패널의 사다리에 항상 표시됩니다.

| 리그 | 컨택 | 선구안 | 인식 지연 | 유인구 반응 | TP |
|---|---|---|---|---|---|
| Amateur | −0.10 | −0.15 | +45ms (일찍 결정) | ×1.25 | ×1.0 |
| KBO Futures (2nd Team) | −0.05 | −0.07 | +22ms | ×1.12 | ×1.2 |
| KBO League (1st Team) | 0 | 0 | 0 | ×1.00 | ×1.5 |
| Minor League (AAA) | +0.05 | +0.07 | −15ms | ×0.90 | ×1.8 |
| Major League Baseball (MLB) | +0.10 | +0.15 | −30ms (끝까지 봄) | ×0.80 | ×2.2 |

인식 지연은 타자가 스윙을 결정하는 시점(플레이트 도착 ≈0.21초 전)에 더해집니다. 지연이 클수록 타자는 변화를 덜 보고 결정합니다.
시즌은 **20경기**입니다 (출퇴근 플레이 기준). 이전 세이브의 30경기 시즌은 그대로 끝까지 진행되고, 다음 시즌부터 20경기입니다. 이닝·승수·탈삼진 기준(승격 100이닝, 콜업 10경기·50이닝, 강등 30이닝, 시상, 명예의 전당 통산 기록)은 30경기 기준값에 시즌 길이 비율(20/30)을 곱해 적용합니다.

### 승격 · 콜업 · 강등

| 리그 | 승격 기준 ERA·FIP | 시즌 중 콜업 ERA / FIP | 강등 ERA |
|---|---|---|---|
| Amateur | ≤ 4.50 | ≤ 3.00 / ≤ 3.50 | — |
| KBO Futures | ≤ 4.20 | ≤ 2.70 / ≤ 3.20 | ≥ 6.20 |
| KBO League | ≤ 3.90 | ≤ 2.40 / ≤ 2.90 | ≥ 5.90 |
| AAA | ≤ 3.60 | ≤ 2.10 / ≤ 2.60 | ≥ 5.60 |
| MLB | (최고 단계) | — | ≥ 5.60 |

- **시즌 후 승격**: ERA와 FIP 둘 다 기준 이하 + 100이닝 이상. 달성하면 승격 또는 잔류를 고를 수 있습니다.
- **시즌 중 콜업**: 10경기·50이닝 이상에서 ERA가 기준보다 1.50, FIP가 1.00 낮으면 경기 후 콜업 제안이 옵니다. 수락하면 같은 해에 상위 리그로 옮겨 남은 일정(최소 5경기)을 소화합니다. 기록실에는 별도 행으로 남고 서비스 연차는 한 해로 셉니다.
- **강등**: 30이닝 이상 던지고 ERA가 기준 +2.00 이상이면 시즌 후 한 단계 내려갑니다 (선택 불가).
- 조건 진행 상황은 경기 결과 화면과 커리어 기록실의 Promotion 카드에서 확인합니다.

### 리그 해금 (난이도 선택)

- 처음 만든 캐릭터는 무조건 **Amateur**에서 시작합니다.
- 어떤 캐릭터로든 승격·콜업으로 도달한 리그는 이 기기에 해금되어(`ace-project-unlocks-v1`), 이후 새 캐릭터를 만들 때 해금된 리그 중에서 시작 리그를 고를 수 있습니다. '새 선수로 시작'으로 기록을 지워도 해금은 유지됩니다.

## 릴리스 미터와 실투 ("!" Meatball Penalty)

- 바늘은 0→1로 올라갔다가 1→2로 되돌아옵니다. 타이밍은 **바늘이 지나온 경로 위의 위치**로 판정하므로 정점 이후의 늦은 릴리스는 대칭으로 봐주지 않습니다.
- 황금 구간(PERFECT)의 폭은 제구 Lv.1 8% → Lv.99 22%.
- 탄착 분산 = 제구 분산 × 배율. 배율은 구간 중앙 0.1× → 구간 경계 0.3× → 구간 밖 1단위 벗어날 때마다 +7×로 **연속적으로** 커집니다 (GOOD ≤ 0.05, 그 밖은 EARLY/LATE).
- 구간 밖으로 0.14 이상 벗어나거나(빨간 빗금 구간), 정점을 지나 한참 늦거나, 미터를 방치하면 **실투(MISS)**:
  - 투수와 조준점 위에 맥박처럼 뛰는 **"!"** 경고, 콜아웃 `실투!`
  - 공이 무브먼트 65%를 잃고 벨트 높이 한가운데로 몰립니다(목표 무시), 구속 −5km/h
  - 타자: 존 스윙 ≥93%, 구종 자동 인식, 타이밍 오차 0, 컨택 품질 +0.32, 타구 속도 +0.38, 홈런 파워 조건 완화

## 타자 기억 (Batter Adaptation Memory)

- 한 경기 안에서 타자별로 지난 타석의 투구(구종·위치·결과)를 기억합니다.
- 2·3번째 대결에서 지난 타석과 **같은 구종**(비중 ×0.45), **같은 존 칸**(3×3, 비중 ×0.6), **같은 구종+칸**(×0.9)을 반복할수록 적응도가 올라갑니다 (첫 재대결 ×0.8, 세 번째부터 ×1.0).
- 적응도는 구종 인식 +30%p, 예상 궤적 오차 −40%, 컨택 품질 +0.24, 타구 속도 +0.25, 유인구 반응 −30%로 반영됩니다.
- **지난 타석 오버레이**: 재대결 타자가 들어서면 존 위에 반투명 ◆ 마커(구종 색·머리글자, 실투는 !)와 타석별 시퀀스 배너가 표시됩니다. `지난 타석` 토글로 끌 수 있습니다.
- 조준 중 적응도가 35%를 넘으면 `읽힘 N%` 경고 배지가 뜹니다.

## 구위: 키·팔 각도·익스텐션·IVB·VAA

- **익스텐션** = 1.55m + (키−160)×0.012 + 팔 각도 보정. 실제 비행 거리(18.44m − 익스텐션)가 짧아져 비행 시간이 줄고 **체감 구속**이 올라갑니다. 타자의 늦음(lateness) 판정은 체감 구속을 씁니다.
- **릴리스 높이** = 키 × 팔 각도 비율 (오버핸드 0.97 … 언더핸드 0.34). 높을수록 **다운힐 플레인**이 가파릅니다.
- **IVB**: 포심 라이드는 오버핸드 ×1.25, 쓰리쿼터 ×1.0, 사이드암 ×0.7, 언더핸드 ×0.45에 키 보정이 곱해집니다.
- **VAA**: 릴리스 높이·익스텐션·구속·목표 높이·IVB로 등가속도 모델을 풀어 계산합니다 (하이존 포심 ≈ −4~−5°).
- **체격 페널티**: 키는 공짜가 아닙니다. 188cm를 넘으면 팔다리가 길어 릴리스 재현이 어려워 **제구 편차가 최대 +35%**(210cm), 몸을 쓰는 에너지가 커 **투구당 체력 소모가 최대 +20%** 늘어납니다. 178cm 미만의 작은 투수는 반대로 제구 편차 최대 −12%, 체력 소모 최대 −8% (대신 익스텐션·플레인·IVB가 작음). 178–188cm는 중립. 생성 화면에서 수치로 확인할 수 있습니다.
- **라이징 착시**: 포심 IVB가 30cm를 넘을수록, 그리고 플레인이 가파를수록 타자가 믿는 라이드가 줄어 높은 직구 아래로 배트가 지나갑니다 (`떠오르는 직구`). 가파른 플레인은 낮게 떨어지는 공의 컨택도 깎습니다 (`수직 낙차`).

## 피치 터널 (Tunneling)

- 터널 지점을 플레이트 앞 **25ft(7.6m)** 로 두고, 그 지점에서 직전 공과의 거리가 **0.85 유닛** 이내면 같은 공으로 보입니다 (기존 판단 시점 비교·0.42 허용치보다 훨씬 관대, smoothstep 감쇠).
- 분기 점수 = 도착 지점 차이 + 구속 차이 + **하이-로우 페어 보너스**(IVB ≥28cm 패스트볼 뒤 큰 낙차 구종, `HI-LO TUNNEL`).
- 효과 증폭: 인식률 −50%p×터널, 유인구 반응 +50%×터널, 컨택 품질 −0.2×터널, 타이밍 예측이 직전 공 구속에 80%까지 끌려감.

## 스태미너 · 교체 · 혹사

- 선발은 약 100구를 던질 수 있습니다: 투구당 1, 전력투구(미터 0.9 이상) +0.8, 주자 있음 +0.35, 풀카운트급 카운트 +0.35. 이닝 사이 회복은 +3뿐입니다.
- 체력 40 미만부터 구속·제구가 떨어지고, **체력 30 미만 또는 120구**가 되면 타자 사이에 감독이 올라와 **교체 신호**를 줍니다.
- 교체 신호는 **경기당 1번만 거부**할 수 있고, 두 번째 신호에서는 반드시 공을 넘겨야 합니다.
- 교체되면 그 경기 등판은 즉시 끝나고 결과 화면 → 다음 경기 / 구종 강화(스탯 찍기)로 넘어갑니다. 남은 이닝은 불펜으로 즉시 계산되어 팀 승패만 정해집니다. 불펜 실점은 투수에게 기록되지 않습니다. 5이닝 이상 + 리드 상태로 내려가 팀이 이기면 승리투수, 뒤진 채 내려가 지면 패전, 그 외는 노 디시전.
- **혹사 여파**: 100구 초과분 ×1.5, 체력 25 미만으로 끝낸 만큼 ×1.2, 교체 거부 1회당 6만큼 다음 경기 시작 체력이 깎입니다 (최대 45). 정상 등판이면 다음 경기는 100으로 시작합니다.

## 커리어 기록실 (Career Stats)

헤더의 트로피 버튼(데스크톱은 좌측 패널)에서 엽니다.

- **서비스 타임**: KBO Futures 이상 시즌부터 프로 연차로 셉니다 (`Year 3 Pro`, 아마추어는 `Amateur Year N`), 데뷔 시즌 표시.
- **Traditional**: G, IP(야구식 `4.2`), W, L, ERA, WHIP, H, HR, BB, SO, HBP
- **Advanced**: FIP = (13·HR + 3·(BB+HBP) − 2·SO) / IP + cFIP, K/9, BB/9, K/BB, BAA
- **cFIP (리그 상수)**: AMA 4.20 · FUT 4.45 · KBO 4.65 · AAA 3.95 · MLB 4.00. 실제 FIP 상수는 리그 평균 ERA에 맞춰 매 시즌 다시 구하는 값(MLB ≈3.10)인데, 이 게임은 하위 리그 K/9가 15 이상이라 3.10을 쓰면 FIP가 ERA보다 한참 낮고 음수까지 나왔습니다(승격 FIP 조건도 사실상 무조건 통과). `pnpm sim:fip`로 이 게임의 득점 환경을 시뮬레이션해 **각 리그 승격 기준 ERA 지점에서 FIP ≈ ERA**가 되도록 보정했습니다. FIP는 ERA 추정치이므로 0 미만은 0.00으로 표시합니다(무결점 이닝 1이닝처럼 표본이 작거나 삼진만 잡을 때 공식상 음수가 나옴). 통산 FIP는 시즌별 상수를 이닝으로 가중 평균합니다.
- 시즌 탭으로 시즌별/통산 전환, 시즌별 표(가로 스크롤)에서 행을 눌러 이동합니다.
- ERA는 비자책 구분 없이 투수 책임 실점 기준, WHIP는 HBP 제외, BAA는 볼넷·HBP 제외.
- 세이브(SV)는 기록하지 않습니다: 공식 기록 규칙상 승리투수는 세이브를 받을 수 없고, 우리 투수는 선발입니다. (이전 버전은 완투승을 세이브로도 함께 셌습니다.)
- **강판 후 승계 주자**: 교체 시 남긴 주자가 득점하면 불펜이 아니라 투수의 실점입니다(1·2·3루 기본 득점 확률 13/27/45%, 아웃 수 보정).
- **승패 판정(교체 시)**: 승리는 5이닝 이상 + 리드 상태로 내려가고 팀이 그 리드를 끝까지 한 번도 잃지 않아야 합니다(불펜이 동점·역전을 허용하면 노 디시전). 패전은 뒤진 채(남긴 주자 실점 포함) 내려가고 팀이 끝까지 동점을 만들지 못한 경우입니다.

## 나이 · 은퇴 · 역대 선수 (Legacy)

- **나이**: 데뷔 나이는 시작 리그별 19/21/23/24/25세. 새 시즌(연도)이 시작될 때마다 +1세 (시즌 중 콜업은 같은 해).
- **에이징 커브**: 24세 이하 성장기 TP +20% · 25–31세 전성기 · 32세부터 구속 매년 −0.8km/h(36세 이후 가속, 최대 −10), 체력 소모 매년 +3% · 34세부터 제구 편차 매년 +2%, TP −10%.
- **은퇴**
  - 강제: 42세 시즌 종료 / 25세 시즌까지 Amateur에서 승격 조건을 못 채우면 "프로 입성 실패".
  - 자발: 한 시즌 이상 뛴 뒤 커리어 기록실의 `은퇴 선언`(두 번 눌러 확인), 30세 이후엔 시즌 결과 화면에서도 `여기서 은퇴`.
- **은퇴식**: 커리어 전체 기록(시즌별·통산, 수상, 명장면)이 담긴 명판을 보여주고 **역대 선수**(`ace-project-legacy-v1`, 기기 단위)에 영구 저장합니다. 이어서 새 신인 드래프트로 넘어갑니다.
- **명예의 전당**: 통산 150승 · 2000K · MLB 5시즌 · MLB 3시즌 이상 ERA 3.00 이하(500이닝+) · 사이영상 2회 · KBO 골든글러브 3회 중 하나.
- **레거시 보너스**: 새 캐릭터는 역대 선수 1명당 +40 TP, 명예의 전당 1명당 +80 TP (최대 400)로 시작합니다. 리그 해금도 그대로 이어집니다.
- 커리어 기록실과 캐릭터 생성 화면에서 `역대 선수`를 열어 과거 캐릭터의 전체 기록을 볼 수 있습니다.

## 리그별 시상

시즌 종료 시 그 시즌 리그에 맞는 상을 판정해 커리어에 영구 기록합니다. 표의 이닝·승·K 기준은 30선발(≈180이닝) 기준이며, 20경기 시즌은 2/3로 환산합니다.

| 리그 | 상 | 기준 |
|---|---|---|
| Amateur | 아마추어 최우수 투수상 / 탈삼진왕 | ERA ≤ 2.50·100IP·10승 / 160K |
| KBO Futures | 퓨처스리그 우수 투수상 / 탈삼진왕 | ERA ≤ 2.80·100IP·10승 / 150K |
| KBO League | 투수 골든글러브 / 최고 투수상 / 탈삼진왕 | ERA ≤ 3.00·150IP·14승 / ERA ≤ 2.40·FIP ≤ 3.00·160IP·170K / 190K |
| AAA | 트리플A 올해의 투수 / 올스타 | ERA ≤ 2.80·130IP / ERA ≤ 3.30·80IP |
| MLB | 사이영상 / 올스타 / 탈삼진왕 | ERA ≤ 2.60·FIP ≤ 3.00·170IP·(15승 or 220K) / ERA ≤ 3.20·90IP / 230K |

완투 경기의 **완투 · 완봉승 · 노히터 · 퍼펙트게임**과 **무결점 이닝**(9구 3삼진)은 경기 번호와 함께 시즌 기록에 남습니다.

| 완투 (교체 없이 27아웃) | +100 | 경기 종료 |

| 노히터 | +350 | 경기 종료 |

경기 기록은 가장 높은 하나만 지급합니다 (퍼펙트게임이면 완투·완봉·노히터는 중복 지급하지 않음). 상단 TP 표시는 10,000 이상이면 `12.6k`처럼 줄여 보여줍니다. 수상은 시즌 결과 화면, 커리어 기록실의 `Awards`, 은퇴 명판에 표시됩니다.

## 수싸움 보조 기능

- **타자 기세(Confidence) 미터**: 헛스윙·삼진·범타는 기세를 꺾고(조급함 → 멘붕), 안타·볼넷은 올립니다(자신감 → 감 잡음). 조급한 타자는 유인구에 최대 30% 더 손이 나가고, 감 잡은 타자는 컨택이 좋아집니다.
- **투구 전 스카우팅 한 줄**: 타자 카드에 약점 구종, 콜드존, 지난 타석에서 노리고 있는 구종, 아직 못 본 구종을 요약합니다 (데스크톱 우측 패널에 전체 리포트와 타석 히스토리).

## 기존 수싸움 요소

- **유인구**: 타자는 공이 "어디로 올 것처럼 보이는지"로 스윙을 결정합니다. 2스트라이크 이후 더 넓게 휘두릅니다.
- **눈높이**: 높은 직구 다음 낮은 변화구는 인식률이 떨어집니다.
- **플래툰**: 같은 손 타자엔 슬라이더·스위퍼, 반대 손 타자엔 체인지업·스플리터가 강합니다.
- **타이밍**: 타자는 가장 빠른 공에 맞추고 본 공의 구속에 적응합니다.

## 출퇴근 업데이트 (Commute Update)

한 번 켜서 3~5분 안에 "던지기 → TP → 강화"가 끝나도록 세션 구조를 바꿨습니다.

- **하이라이트 모드 (기본값)**: 1회 선두 타자 · 라이벌 · 득점권 위기 · 9회 1점 차 접전만 직접 던집니다. 나머지 타석은 같은 물리·타자 모델로 자동 진행되고(안정적인 릴리스, 상황별 볼배합), 기록·체력·교체 규칙이 그대로 적용됩니다. 자동 타석 TP는 70%. 자동 진행 중에는 투구 버튼이 잠기고, 결과가 경기장 하단 `AUTO` 피드로 표시됩니다. 경기당 직접 던지는 타석은 약 13타석(≈40구).
- **풀 모드**: 모든 공을 직접 던집니다. 도움말·이닝 결과·이어하기 화면에서 전환합니다.
- **이어하기 카드**: 앱을 다시 열면 현재 상황(이닝·아웃·주자·점수), 출석 보상, 오늘의 미션을 보여줍니다.
- **출석 · 일일 미션**: 매일 첫 접속 시 연속 출석 보상(20 × 연속 일수, 최대 7일). 날짜로 정해지는 미션 3개(직접 삼진, PERFECT 릴리스, 무실점 이닝, 경기 완료, 강화, 코너 루킹, 유인구 헛스윙) — 미션당 50 TP, 올클리어 100 TP (리그 배율 적용). 자동 타석은 집계하지 않습니다. `ace-project-daily-v1`.
- **성장 체감**: 강화할 때마다 전/후 수치 토스트(구속 km/h, 황금 구간 %, 무브먼트 cm). 140~165km/h 돌파, 투수 LV, 레퍼토리 수 마일스톤. 훈련실·이닝/경기 결과 화면의 **추천 강화** 버튼(가장 많이 쓴 2구종 중 가장 낮은 스탯, 동률이면 제구 우선)을 한 번 누르면 바로 강화됩니다.
- **이번 세션 TP**와 자동 저장 안내를 이닝 결과에 표시합니다.
- **튜토리얼**: 첫 투구까지 3단계 코치 말풍선(존 터치 → 투구 버튼 → 황금 구간 탭).
- **점진 공개**: Amateur에서는 타자 기세·심리 칩과 터널 배지를 숨기고 KBO Futures부터 보여줍니다. IVB·VAA·체감 구속과 전술 설명은 `상세` 토글(경기장 우하단/도움말)에서 켭니다. 판정 로직은 리그와 무관하게 동일합니다.
- **설정 저장**: 소리·진동·존 선·핫존·지난 타석·상세·플레이 모드·튜토리얼 완료를 기기에 저장합니다 (`ace-project-settings-v1`).
- **PWA / 오프라인**: 홈 화면에 설치할 수 있고(manifest, 아이콘), 서비스 워커가 앱 셸과 빌드 자산을 캐시해 지하철처럼 연결이 끊겨도 플레이됩니다 (프로덕션 빌드에서만 등록).
- **이름 중복 수정**: AAA·MLB 타선이 매 경기 같은 9명 이름이던 문제, 모든 리그 라이벌이 같은 3명이던 문제를 고쳤습니다. 타선 안 이름 중복 없음, 리그별 라이벌 3명, 상대 팀은 현재 리그의 4개 팀 안에서 순환하며 같은 팀과 연속으로 만나지 않습니다.
- **화면 정리**: 리그 배너와 등판 목표/챌린지 줄을 한 줄(`리그·경기 수 | 등판 목표 | 오늘 | 3분 챌린지`)로 합쳤습니다. 색 역할을 민트=행동, 골드=보상(TP·업적), 레드=위험(실투·체력), 블루=정보로 나누고, 선택된 구종 칩은 구종 색 테두리와 점으로만 표시합니다.

## 사운드

`public/audio/`의 녹음 샘플(총 약 76KB)을 Web Audio로 재생하고, 불러오기 전이나 실패하면 기존 신시사이저 소리로 대체합니다.

| 파일 | 용도 | 처리 |
|---|---|---|
| `whoosh.mp3` | 릴리스 (구속이 빠를수록 높고 짧게) | 페이드 |
| `catch.mp3` | 포구 · PERFECT 스트라이크 | 페이드 |
| `hit.mp3` | 안타 · 홈런 타구음 | 금속 잔향 페이드 |
| `crowd.mp3` | 안타 · 홈런 · 구종 해금 · 마일스톤 환호 | 250–3200Hz 대역 필터 (잡음처럼 들리던 고역 제거) |
| `levelup.mp3` | 강화 · 구종 해금 | 음 경계 클릭 제거 |
| `bgm.mp3` | 배경음악 「스트라이크 존으로」 (3분, 첫 화면부터 재생, 끝에서 페이드 후 다시 시작, 앱을 숨기면 정지) | 원본 3.9MB(48kHz 174kbps) → 1.8MB(44.1kHz 80kbps 스테레오) |

효과음: 원본 WAV 705KB → MP3 36KB. 배경음악은 메모리에 풀지 않고 스트리밍 재생하며, Web Audio 게인으로 볼륨을 조절해 iOS에서도 동작합니다.

**설정(헤더 톱니바퀴)**: 전체 소리 ON/OFF, 배경음악 볼륨, 효과음 볼륨(기본 50 / 80), 플레이 모드, 진동, 존 선, 상세 수치. 브라우저 자동 재생 제한 때문에 배경음악은 첫 터치 후 시작됩니다. 음성 파일(`voice_*.wav`)은 말소리가 아니라 0.45초짜리 일정한 음(화음)이라 판정 음성으로 쓰지 않았고, `whistle_call.wav`는 기존 삼진 효과음과 겹쳐 제외했습니다. 서비스 워커가 `/audio/`를 캐시해 오프라인에서도 소리가 납니다.

## UI

상대 타자 카드는 작고 반투명하게(텍스트 그림자로 가독성 유지) 만들어 경기장을 가리지 않습니다. 다크 슬레이트 · 스타디움 잔디 그린 · 화이트 · 네온 앰버/시안 테마, 홈플레이트 방패 로고. 모바일은 한 화면 세로 레이아웃(경기장 캔버스가 남는 높이에 맞춰 축소), 700px 이상은 카드형, 1100px 이상은 좌측 투수 패널 / 우측 스카우팅 패널이 붙는 3단 레이아웃입니다. 1920×1080 · 1366×768 · 1024×768 · 768×1024 · 390×844 · 375×667에서 가로 스크롤·텍스트 잘림 없이 투구 버튼이 화면 안에 들어오는지 확인했습니다.

## 저장

`localStorage`(`ace-project-save-v2`)에 프로필·경기·현재 시즌·지난 시즌 기록을 저장합니다. 이전 세이브의 난이도 값은 무시되고, 새 필드(타자 기억, 기세, HR/HBP, 세이브, 피로)는 기본값으로 채워집니다. 과거 경기의 투구 위치나 시즌 기록은 만들어내지 않습니다.

## 아케이드 업데이트

- **기술 보상:** 실제 터널 삼진·높낮이 배합·코너 루킹·3구 이내 범타·병살·위기 탈출·12구 이하 무실점 이닝에 추가 TP와 숙련도를 지급합니다. 기술 TP는 한 공 최대 32, 집중 충전은 기술 최대 24 + 아웃 4로 제한합니다. 유인구를 위한 볼은 진행도를 초기화하지 않습니다.
- **집중 투구:** 집중 100에서 다음 한 공을 장전합니다. 실제 투구 시 소모하며 미터가 느려지고 PERFECT 기본 탄착 분산이 45% 줄어듭니다. 실투와 타자 판정은 그대로 적용됩니다. 경기마다 게이지는 초기화됩니다.
- **안정/전력:** 전력 투구는 구속 +3km/h, 빠른 미터, 기본 분산 ×1.3, 체력 추가 소모 1.2. 안정 투구는 기존 동작입니다.
- **숙련 특성:** 숙련 Lv.4(225 XP)부터 구종별 핀포인트/시그니처 중 하나를 선택합니다. 핀포인트는 기본 분산 ×0.8, 시그니처는 구종별 고유 효과입니다. 등판 중 변경은 잠기며 경기 전·종료 후 무료로 변경합니다.
- **병살:** 1루 주자·2아웃 미만·비실투 땅볼에서 발생합니다. 낮은 코스, 먹힌 타구, 싱커 시그니처가 확률을 높입니다. 타수는 하나, 아웃은 둘로 기록합니다.
- **등판 목표:** 첫 투구 전에 코너 5회 / 12구 이하 무실점 이닝 / 서로 다른 2구종 삼진 중 하나를 선택합니다. 2구종 목표는 실제 보유 구종이 2개 이상이어야 합니다. 달성 시 60 TP에 리그·나이 배율을 적용하며 중복 지급하지 않습니다.
- **개인 활약:** 경기 종료 후 다음 경기로 이동할 때 이닝·삼진·실점·볼넷에 따른 최대 150 기본 TP를 추가합니다. 팀 득점 지원과 독립적으로 계산합니다.
- **라이벌:** 리그마다 교타·장타·선구안형 고정 라이벌 3명이 상대 팀에 따라 등장합니다. 직전 대결의 최대 3타석을 다음 재대결에도 기억합니다.
- **챌린지:** 9회 1점 차 / 무사 만루 / 20구 / 강타자 3명. 고정 Lv.40, 별도 최고 기록(`ace-challenges-v1`), 커리어 기록·TP와 분리됩니다. 챌린지 도중 닫으면 해당 시도는 종료됩니다.
- **구속 분포:** 타자가 실제 본 구종별 구속과 최근 투구 분포로 예상 도착 시간을 갱신합니다. 구종 인식과 반복 노출은 적응을 돕고 터널은 기만을 유지합니다. 큰 구속 차이 자체에 파울 보너스를 부여하지 않습니다. 훈련실에 기본 구속 비교와 강화 전후 수치를 표시합니다.
- **화면:** 네이비·민트·골드 테마, 등판 목표/챌린지 진입, 집중 게이지, 특성 선택, 개인 평가 카드. 작은 화면은 필요한 경우 세로 스크롤을 허용하며 모달은 독립적으로 스크롤됩니다.

구속 모델은 실제 MLB 데이터를 회귀 분석한 모델이 아닌 게임용 근사입니다. 참고: [MLB 체인지업 설명](https://www.mlb.com/glossary/pitch-types/changeup), [투구 시각 정보와 타격 정확도 연구](https://baseball.physics.illinois.edu/EyesWideShut.pdf).
